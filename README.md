College Student Management System


-Introduction

   The College Student Management System is a project developed to manage student records digitally.
   It helps in storing, updating, searching, and deleting student information using a database.
   This project is useful for colleges and educational institutes to manage student data efficiently.

-Features
   Add new student records
   View student details
   Update student information
   Delete student records
   Search student data
   Database connectivity using MySQL
   Simple and user-friendly interface
   Technologies Used
   Python
   MySQL
   VS Code
